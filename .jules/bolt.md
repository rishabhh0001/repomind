
## 2023-10-25 - Prevent N+1 queries in async SQLAlchemy with list comprehensions
**Learning:** In async SQLAlchemy (`asyncpg`, `aiosqlite`), lazy loading relationship properties like `s.parent` inside a synchronous context (e.g. list comprehension) causes an N+1 query issue or raises a `MissingGreenlet` error if the object is not cached in the identity map. Even if it is in the identity map (because the query was `select(Symbol).where(repo_id==repo_id)` returning all elements), using `s.parent` will force SQLAlchemy to evaluate the relation synchronously, adding hidden overhead.
**Action:** When extracting large sets of inter-connected entities (like tree nodes), instead of depending on relationship attribute lazy evaluation, utilize the fact that all entities are already fetched in Python memory. Map them to a dictionary by ID (`symbol_map = {s.id: s.qualified_name for s in symbols}`) and resolve relationships using an O(1) dictionary lookup (e.g. `symbol_map.get(s.parent_id)`).
